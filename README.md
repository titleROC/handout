### 内容结构

- **学习导航**：课程标准要求、学习目标（按核心素养）、考情分析与命题规律、知识框架图、知识回顾与预习自测
- **一、电磁感应现象中的感生电场**：感生电场的特点，与静电场的比较，感生电动势与动生电动势，电子感应加速器（“1/4 周期”和“2:1 条件”）
- **二、涡流**：演示实验，涡流的概念、方向与影响因素，热效应、磁效应、力效应，真空冶炼炉、电磁炉、高频焊接、金属探测器、涡流探伤等应用，硅钢片叠压铁芯（含叠片方向）与铁氧体
- **三、电磁阻尼**：阻尼摆、强磁体在铜管中下落，磁电式电表，电磁阻尼的四个特点及应用（涡流制动、磁力刹车、缓速器、精密仪器减振等）
- **四、电磁驱动**：转动磁铁带动铝框，“同向”与“异步”的原因，感应电动机、车速表、感应式电能表，阿拉果圆盘与傅科电流，阻尼与驱动的比较
- **五、定量分析**：只受安培力的阻尼运动（动力学、动量、能量三观点，$v$–$x$ 线性关系）、收尾速度、$F=kv$ 型阻力、运动磁场中的电磁驱动
- **六、总结提升**：一表通览，楞次定律“阻碍”的四种表现，解题“四步走”，14 条易错辨析
- **七、课后练习**：A 组基础巩固、B 组能力提升、C 组拓展创新，共 17 题
- **参考答案与解析**（仅教师版）

全书含 17 道例题（其中 2014 江苏卷、2015 全国卷Ⅰ为真题原题，2017 全国卷Ⅰ、2023 全国乙卷为改编题；练习第 1 题为 2020 全国卷Ⅱ原题），插图均为 TikZ 绘制。

### 编译

需要 TeX Live（XeLaTeX、`ctex`、`tcolorbox`、`siunitx`、TikZ 等）、`latexmk`，以及以下字体：

- Noto Serif CJK SC / Noto Sans CJK SC（正文宋体、标题黑体）
- TeX Gyre Termes 与 TeX Gyre Termes Math（西文与数学）
- FandolKai、FandolFang（楷体、仿宋，TeX Live 自带）

```bash
cd eddy-current
make            # 同时生成教师版和学生版
make teacher    # 只生成教师版
make student    # 只生成学生版
make clean      # 清理中间文件
```

`main.tex` 编译出教师版；`student.tex` 先定义 `\StudentVersion` 再读入 `main.tex`，编译出学生版。样式集中在 `preamble.tex`，正文按章节放在 `sections/` 目录。
